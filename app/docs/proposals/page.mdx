# Writing Proposals

## Creating a new proposal

Open **Proposals** and click **New Proposal** (or press <kbd>Ctrl</kbd>+<kbd>N</kbd> on that page). Optionally link an RFP analysis so the AI can use its requirements.

## Using the editor

Proposals are made of sections shown on the left. Select a section to edit it in the rich-text editor. Your work is saved automatically two seconds after you stop typing; press <kbd>Ctrl</kbd>+<kbd>S</kbd> to save immediately.

## AI generation features

- **Generate with AI** drafts a single section from your prompt and RFP context.
- **Generate Full Proposal** creates the standard sections in one go.
- Generation usually takes 20–40 seconds. Review the preview, then insert it into the editor.

## Slash commands reference

Select text in the editor and choose one of the six AI commands from the floating menu:

| Command | What it does |
| --- | --- |
| Improve Writing | Improves clarity and flow |
| Make Shorter | Makes the text more concise |
| Expand | Expands with more detail |
| Convert to Bullets | Converts the text into bullet points |
| Make Formal | Rewrites in a formal tone |
| Summarize | Produces a short summary |

## Exporting (PDF and Word)

Use **Export** in the editor toolbar and choose PDF or Word (.docx).

## Sharing with your team

Click the share icon to create a share link with view or comment permission, then copy the link. Teammates can also leave comments on sections and restore earlier versions from the version history.
